YouTube Agent Skill: 11 skills grátis do Claude para o seu canal do YouTube

Baixar o PDFComo instalar
O que é

Pacote gratuito e de código aberto para o Claude Code, criado por Jake Schincariol (repositório Jakeschincariol/youtube-agent-skill, licença MIT, mais de 6 mil estrelas no GitHub em 19/11/2026).

Segundo o README (resumo e tradução nossos): são onze skills do Claude para tocar um canal do YouTube. Não pede cadastro, não pede chave de API e não se liga ao seu canal. Elas escrevem; quem grava e publica é você.

As 11 skills (comandos copiados do README, com explicação traduzida por nós)
/yt-script

uma ideia vira roteiro: 5 ganchos a partir de 21 fórmulas, com nota, e o roteiro falado

/yt-package

título e thumbnail como uma dupla, conferidos para não cortar, não repetir e não ficar vagos

/yt-edit

a transcrição vira lista de cortes: silêncios, vícios de fala e regravações, com o tempo de cada um

/yt-comment

separa os comentários em quatro grupos, escreve respostas no seu jeito e diz qual fixar

/yt-plan

uma semana do tamanho das horas que você tem: um vídeo principal, um mais simples e três Shorts

/yt-viral

o que está funcionando no seu nicho, ordenado por quanto cada vídeo superou a mediana do próprio canal

/yt-retention

lê o seu relatório de retenção: onde o gancho vaza, as quedas e o que mudar

/yt-shorts

os Shorts que já existem dentro de um vídeo longo, com uma primeira frase nova para cada um

/yt-seo

a descrição, as tags que valem a pena e as três buscas que o vídeo deve ganhar

/yt-chapters

capítulos a partir da transcrição, conferidos com as regras do YouTube

/yt-audit

o canal inteiro, terminando em UMA correção, não em vinte

Como instalar (copiado do README)

Jeito 1. Cole isto no Claude:

https://github.com/Jakeschincariol/youtube-agent-skill Install this skill, then confirm /yt-script works.

Jeito 2. Como plugin, no Claude Code:

/plugin marketplace add Jakeschincariol/youtube-agent-skill /plugin install youtube-agent

Jeito 3. Na mão, no Claude Code:

git clone https://github.com/Jakeschincariol/youtube-agent-skill.git cp -r youtube-agent-skill/skills/yt-* ~/.claude/skills/
Primeiro passo depois de instalar: o seu jeito de falar

O README pede dez minutos no arquivo templates/voice.md. Copie para ~/.claude/youtube/voice.md e preencha, ou mande para o Claude três vídeos seus e diga (frase do README, em inglês):

write my voice.md from these

Todas as skills leem esse arquivo. É ele que faz o roteiro sair com a sua cara.

Como começar (sugestão nossa, não está no README)
  1. /yt-viral com 3 canais do seu nicho, para achar a ideia que já funcionou.
  2. /yt-script com essa ideia, para sair com o gancho e o roteiro.
  3. /yt-package para o título e o texto da thumbnail do mesmo vídeo.

As skills são escritas em inglês. Peça "responde em português do Brasil" se o Claude responder em inglês.

Atenção (o que o próprio README avisa)
  • Ela não publica. Cada skill termina num bloco para você copiar. Gravar e subir o vídeo é com você.
  • A nota do gancho é uma heurística, não uma previsão. Foi calibrada com 74 ganchos reais. Nota baixa é motivo para olhar de novo; nota alta não é promessa.
  • O /yt-viral só lê listagens públicas. Não entra na sua conta e não mexe nas suas credenciais.
  • Tags quase não importam, e o pacote diz isso em vez de vender um gerador de tags.
  • Nenhuma skill inventa número. Se faltar um dado, ela pede ou escreve a frase sem ele.
  • Seis das skills usam pequenos programas em Python 3, sem dependências. Sem o Claude Code dá para colar um SKILL.md no começo de uma conversa, mas você perde esses programas.
Atenção (nossa)
  • No reel, os 50 mil de visualizações são a história da cena, não um resultado medido. A skill ajuda a escolher a ideia e a escrever; ela não garante visualizações.
  • O único custo é o uso do seu plano do Claude.
