O que é

Coleção gratuita de skills de marketing para agentes de IA, criada por Corey Haines (repositório coreyhaines31/marketingskills, licença MIT).

Segundo o README (resumo e tradução nossos): é feita para fundadores e profissionais técnicos de marketing que querem que o agente ajude com otimização de conversão, copywriting, SEO, analytics e crescimento. Funciona com Claude Code, OpenAI Codex, Cursor, Windsurf e outros agentes compatíveis com o padrão Agent Skills.

As que aparecem no vídeo (nomes das skills no repositório)
copywriting

texto de página (home, landing page, página de preços)

pricing

preço e pacotes

launch

lançamento de produto ou de funcionalidade

ads

anúncios pagos no Google, Meta e LinkedIn

product-marketing

é a base. Cria o documento com o contexto do produto, que as outras skills consultam primeiro.

Há dezenas de outras (SEO, e-mails, cadastro, onboarding, indicação e mais). A lista completa está no README.

Como instalar (comandos copiados do README)

Opção 1, pelo terminal (a recomendada pelo autor)

npx skills add coreyhaines31/marketingskills

Para instalar só algumas:

npx skills add coreyhaines31/marketingskills --skill cro copywriting

Se for pedir para o próprio Claude Code instalar, o README manda indicar o agente:

npx skills add coreyhaines31/marketingskills -a claude-code

Opção 2, plugin do Claude Code

/plugin marketplace add coreyhaines31/marketingskills /plugin install marketing-skills
Como usar

Depois de instalar, basta pedir a tarefa. Exemplos do README, traduzidos por nós:

"Escreva o texto da home do meu SaaS"

usa a skill copywriting

"Me ajude a otimizar esta landing page para conversão"

usa a skill cro

Também dá para chamar direto:

/cro, /emails, /seo-audit

Sugestão nossa: comece pela product-marketing, contando o que o seu app faz e para quem ele é.

Atenção
  • O comando /plugin só funciona na sessão interativa do Claude Code no terminal. Segundo o README, ele não está disponível no Claude Code na web. Nesse caso, use a opção 1.
  • O material está em inglês e muitos exemplos são de produtos de software (observação nossa).
  • O README divulga serviços pagos do autor e parceiros patrocinadores. As skills em si são gratuitas.
